# Homebrew tap

Homebrew formulae for [Derbent](https://github.com/tunahanaliozturk/derbent), one guarded pass for all
your coding agents.

```bash
brew install tunahanaliozturk/tap/derbent
derbent version
```

The formula installs the prebuilt binary from the matching Derbent release on macOS and Linux, amd64
and arm64, and checks it against the hash in that release's `SHA256SUMS`. Every Derbent release can be
rebuilt byte for byte from its tag; [Install and set up](https://github.com/tunahanaliozturk/derbent/blob/main/docs/install.md)
says how.
